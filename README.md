## Descripción del Proyecto
Este proyecto representa la evolución de la landing page estática de EcoConnect hacia una Arquitectura de Página Única (SPA) utilizando React y el empaquetador Vite. La interfaz fue transformada por medio de un sistema de componentes funcionales y modulares; se mantiene el diseño con el framework Tailwind CSS.

## Estructura de Componentes
La interfaz de usuario fue segmentada en la carpeta `src/components/`:
- `Header.jsx`: Barra de navegación global.
- `Home.jsx`: Sección principal de presentación de la propuesta ambiental.
- `Form.jsx`: Interfaz de captura de datos de usuario.
- `Noticias.jsx`: Sección con información sobre campañas.
- `Footer.jsx`: Pie de página y derechos de autor.
